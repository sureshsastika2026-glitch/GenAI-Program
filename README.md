# GenAI-Program

This repository contains a small collection of Python programs, browser automation experiments, and generated project artifacts. The examples range from a student grade manager to scraping/automation scripts and a sample meal-planning output.

## Repository contents

- `grade_manager.py` — interactive command-line grade manager for managing student marks and grades.
- `cricbuzz_score.py` — Playwright-based script that opens Cricbuzz live scores, detects score-like text, and saves a screenshot as `score.png`.
- `playwright_basic.py` — minimal Playwright example that opens a website and prints the page title.
- `pyautogui.py` — simple PyAutoGUI setup example with a failsafe and pause configuration.
- `south-indian-vegetarian-meal-plan/` — sample meal-planning artifacts including text output and screenshots for an Indian vegetarian meal plan.
- `score.png` — screenshot generated by the Cricbuzz score script.

## Features

- Student grade tracking with input validation
- Grade calculations based on marks from 0 to 100
- Browser automation using Playwright
- Example for web page inspection and screenshot capture
- Demo project folder with generated meal-plan visuals and notes

## Requirements

Python 3.8 or newer is recommended.

Install the required packages:

```bash
python -m pip install playwright pyautogui
```

Then install the browser used by Playwright:

```bash
python -m playwright install chromium
```

## How to run

From the repository root:

```bash
python grade_manager.py
python cricbuzz_score.py
python playwright_basic.py
```

## Notes

- `grade_manager.py` uses only Python's standard library.
- `cricbuzz_score.py` depends on an internet connection and the Playwright Chromium browser.
- `pyautogui.py` is only a configuration example; it does not automate a task by itself.
- The Cricbuzz live score page content can change over time, so the script may need adjustments if the site layout changes.
- The meal-plan directory contains images and a text file used as demonstration output for a sample South Indian vegetarian plan.
